# Fiel Amigo - sitio web

Sitio estático (HTML y CSS) con el catálogo de una tienda de insumos para mascotas de Valdivia.
Proyecto académico: algunos precios y datos son provisorios.

## Estructura

- `index.html`: inicio.
- `perros.html`, `gatos.html`, `accesorios.html`: catálogo.
- `pedido.html`: formulario de pedido (Google Forms) insertado.
- `nosotros.html`, `contacto.html`: información de la tienda.
- `css/estilos.css`: estilos y colores.
- `img/`: logotipo y fotografías.

## Actualizar el catálogo

1. En la página de la categoría, copiar un bloque `<article class="producto">` y cambiar foto, nombre y precio.
2. Guardar la foto en `img/`.
3. Usar el mismo nombre en el formulario y en la planilla de ventas.
4. Revisar en el navegador y subir los cambios a la rama `main`.
